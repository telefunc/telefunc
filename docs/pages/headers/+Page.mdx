**Environment**: client.

Send additional HTTP headers to be sent along Telefunc HTTP requests.

Usually used for sending authentication headers.

```ts
// Environment: client

import { config } from 'telefunc/client'

config.headers = {
  Authorization: `Bearer ${token}`
}
```

> To set headers on a **single call** rather than globally, use <Link text={<code>withContext()</code>} href="/withContext" />.
