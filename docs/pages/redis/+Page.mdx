Redis-backed <Link href="/channel#broadcast">broadcast</Link> fan-out across server instances — a `publish()` on any instance reaches every `subscribe()` on every other instance. <Link href="/room">Rooms</Link> work across instances too.

> You only need this if you scale horizontally — see <Link href="/stream/scale" />.

## Install

```bash
npm install @telefunc/redis ioredis
```

```ts
// Environment: server

import IORedis from 'ioredis'
import { installRedis } from '@telefunc/redis'

const redis = new IORedis('redis://localhost:6379', { maxRetriesPerRequest: 0 })
installRedis(redis)
```

That single call installs the Redis backend for both Broadcast and Room. Room state and events are then shared across server instances.

### Sharing an existing client

Pass an existing [`ioredis`](https://github.com/redis/ioredis) Redis or Cluster instance when you want to share a connection or set options such as TLS or authentication.

```ts
// Environment: server

import IORedis from 'ioredis'
import { installRedis } from '@telefunc/redis'

const redis = new IORedis(process.env.REDIS_URL, { tls: {}, maxRetriesPerRequest: 0 })
installRedis(redis)
```

Telefunc duplicates the supplied client as needed without disconnecting it, so you can continue to use it alongside Telefunc.

## Channels

`Channel` is per-instance. Reconnects must land on the instance holding the channel's state, so multi-instance deployments need sticky sessions at the load balancer. See <Link href="/stream/scale" />.
