```
[telefunc@1.2.4][Warning] telefunc@1.2.3 and telefunc@1.2.4 are both loaded, which is highly discouraged: use a single version of Telefunc, see https://telefunc.com/warning/version-mismatch
```

This warning means that your app loads two different versions of Telefunc (`telefunc@1.2.3` and `telefunc@1.2.4`).

> If the warning shows `an older version of Telefunc`, then that version is too old to tell which one it is.


## Why

With two different versions of Telefunc, telefunction calls can fail with `500 Internal Server Error`.


## Solution

Find the dependency that installs the other version:

```bash
npm ls telefunc
```

> With pnpm, run `pnpm why telefunc`.

Update that dependency to a version that uses the same Telefunc version as your app.

If there isn't one, set `overrides` in the `package.json` at the root of your project, so that only one version of Telefunc is installed:

```json
{
  "overrides": {
    "telefunc": "$telefunc"
  }
}
```

> The value `$telefunc` stands for the version of `telefunc` that this `package.json` depends on. If it doesn't depend on `telefunc`, write the version instead.

> With pnpm, set [pnpm's `overrides`](https://pnpm.io/settings/dependency-resolution#overrides) instead.
