**Environment**: server.

`getContext()` allows telefunctions to type-safely access the Telefunc request context.

It's most commonly used for implementing permissions, see <Link href="/permissions" />.

```ts
// TodoList.telefunc.ts
// Environment: server

import { Abort, getContext } from 'telefunc'

export async function onLoad() {
  const { userId } = getContext()
  if (!userId) {
    throw Abort()
  }

  // ...
}
```

## Provide

You can add `context` properties when calling `telefunc.serve()` — see <Link href="/Telefunc" />.

> You can also provide `context` outside the server middleware (e.g. when <Link href="/testing">testing</Link>) via <Link href="/provideTelefuncContext"><code>provideTelefuncContext()</code></Link>.

## Type safety{#typescript}

You can use a generic type argument to set the type locally...

```ts ts-only
// *.telefunc.ts

import { getContext } from 'telefunc'

type UserContext = { userId: string }

export async function someTelefunction() {
  // TypeScript knows that `userId` is a `string`
  const { userId } = getContext<UserContext>()
}
```

...or declare the `Telefunc.Context` type globally.

```ts ts-only
// TelefuncContext.d.ts

declare global {
  namespace Telefunc {
    interface Context {
      userId: null | string
    }
  }
}

// Add this line if TypeScript complains about `declare global` (it requires the file
// to have at least one `import` or `export` so that TypeScript treats it as a module).
// https://typescriptlang.org/docs/handbook/2/modules.html#how-javascript-modules-are-defined
export {}
```

```ts ts-only
// *.telefunc.ts

import { getContext } from 'telefunc'

export async function someTelefunction() {
  // TypeScript still knows that `userId` is a `null | string`
  const { userId } = getContext<UserContext>() // [!code --]
  const { userId } = getContext() // [!code ++]
}
```

## Call order{#access}

Make sure to call `getContext()` before any `await` operators:

```ts
// TodoList.telefunc.ts

export async function myTelefunction() {
  // ✅ Good: getContext() is called before `await`
  const context = getContext()
  await something()
}
```

If you call `getContext()` after an `await` operator...

```ts
// TodoList.telefunc.ts

export async function myTelefunction() {
  await something()
  // ❌ Wrong: getContext() must be called before `await something()`
  const context = getContext()
}
```

...you will see this error:

<CodeBlockTransformer lineBreak="break-word">
```
[telefunc][Wrong Usage][getContext()] Cannot access context object, see https://telefunc.com/getContext#access
```
</CodeBlockTransformer>
