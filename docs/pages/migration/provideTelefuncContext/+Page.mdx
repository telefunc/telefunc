You must now call your telefunction inside the `provideTelefuncContext()` callback:

```js
// Environment: server

provideTelefuncContext(context) // [!code --]
const { todoItems } = await onLoadTodoItems() // [!code --]
const { todoItems } = await provideTelefuncContext(context, () => onLoadTodoItems()) // [!code ++]
```
