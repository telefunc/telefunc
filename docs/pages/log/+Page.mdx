**Environment**: server  
**Default**: `{ shieldErrors: { dev: true, prod: true } }{:ts}`

Whether to log shield validation errors.

In production, the logged error names the telefunction, its file, the path of the value with the wrong type and the expected type, and leaves out the data sent (it may contain passwords or other secrets). In development, when the arguments of a telefunction call fail the shield, the error also lists the arguments passed.

```ts
// Environment: server

import { config } from 'telefunc'

config.log.shieldErrors = true
// Or
config.log.shieldErrors = { dev: true, prod: true }
```
