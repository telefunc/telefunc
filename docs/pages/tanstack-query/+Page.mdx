Live queries for [TanStack Query](https://tanstack.com/query) — a telefunction returns a live value, and every connected client subscribed to it refetches automatically whenever the server invalidates it.

<PoweredByTelefuncStream pkg="tanstack-query" />

## Install

```bash
npm install @telefunc/tanstack-query
```

Create a `liveQuery` helper from your `QueryClient`:

```tsx
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'
import { createLiveQuery } from '@telefunc/tanstack-query'

const queryClient = new QueryClient()
const liveQuery = createLiveQuery(queryClient)

function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <MyApp liveQuery={liveQuery} />
    </QueryClientProvider>
  )
}
```

> `createLiveQuery()` doesn't modify the `QueryClient` — it returns a `liveQuery()` options helper you spread into `useQuery()`. Any TanStack Query adapter works: React, Vue, Svelte, Solid.


## Live queries

A live query has two halves: the **telefunction returns a `Live` value** (server-owned liveness), and the client wraps its `useQuery()` options with **`liveQuery()`**.

Server — return a `Live` and bind it to a server-owned tag:

```ts
// TodoList.telefunc.ts
// Environment: server
import { Live } from 'telefunc'

const TODOS_TAG = 'todos'

export async function getTodos() {
  const live = new Live<Todo[]>([])
  Live.onInvalidate(TODOS_TAG, live) // subscribe BEFORE the first await (see the rule below)
  live.set(await readTodos())
  return live.client
}
```

> **Subscribe before fetch.** `Live.onInvalidate()` must run before the telefunction's first `await` — it binds the tag while the request context is still available. Fill the data with `live.set()` after your `await`.

Client — wrap the query options with `liveQuery()`:

```tsx
import { useQuery } from '@tanstack/react-query'
import { getTodos } from './TodoList.telefunc'

function Todos({ liveQuery }) {
  const { data: todos } = useQuery(
    liveQuery({
      queryKey: ['todos'],
      queryFn: () => getTodos(), // returns ClientLive<Todo[]>; liveQuery unwraps `data` to Todo[]
    }),
  )
  // ...
}
```

> `liveQuery()` forwards every TanStack option (`staleTime`, `gcTime`, `select`, …). Only the `data` type changes: `queryFn` returns `ClientLive<T>` and `data` surfaces as `T`.


## Invalidation

Liveness is server-driven: call `Live.invalidate(tag)` on the server whenever the underlying data changes — from a mutation telefunction, a background job, a webhook, anywhere on the server:

```ts
// TodoList.telefunc.ts
// Environment: server
import { Live } from 'telefunc'

export async function addTodo(text: string) {
  await writeTodo(text)
  Live.invalidate('todos') // every client with a live query bound to 'todos' refetches
}
```

> There's no client-side invalidation to wire: `Live.invalidate()` reaches every connected client whose live query is bound to that tag, and each one refetches.


## Two rules

1. **`queryFn` must call a telefunction that returns a `Live` value.**
1. **Return the telefunction call directly.** Transform with `select` instead of inside `queryFn`:
   ```js
   // ❌ Broken: queryFn doesn't return the ClientLive directly
   queryFn: async () => (await getTodos()).length

   // ✅ Return the call directly, transform with select
   queryFn: () => getTodos(),
   select: (todos) => todos.length,
   ```
   > `liveQuery()` must access the `ClientLive` the telefunction returns, so it can unwrap the data and wire invalidation.


## How it works

1. The telefunction returns a `Live`; it crosses the wire and the client subscribes to invalidations for its tag.
   > The client subscribes only if the telefunction call succeeds (i.e. it doesn't throw), so <Link href="/permissions">authorization</Link> is respected.
1. When the server calls `Live.invalidate(tag)`, an invalidation event is <Link href="/channel#broadcast">broadcast</Link> to every subscribed client.
1. Each client calls [`invalidateQueries()`](https://tanstack.com/query/latest/docs/framework/react/guides/query-keys) for the matching query key, which refetches (a mid-flight fetch is cancelled and restarted, so an invalidation is never dropped).

> Live queries are powered by <Link href="/stream">Telefunc Stream</Link> under the hood (in particular <Link href="/channel">channels</Link> and <Link href="/channel#broadcast">broadcasts</Link>).
