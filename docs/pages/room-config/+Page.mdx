Set how long a <Link href="/room">room</Link> stays open once nobody uses it.

```ts
// /server/index.ts
// Environment: server

import { roomConfig } from '@telefunc/room'

roomConfig.emptyTimeout = 300_000    // Close a room that nobody joined yet, once no page has it open (ms)
roomConfig.departureTimeout = 20_000 // Close a room after the last participant leaves and no page has it open (ms)
```

Set these defaults in your server entry. Override either timeout when you call `Room.create()` or `Room.getOrCreate()` to create a room.

> Set both to `Infinity` to keep a room open until <Link href="/room#close-a-room">`Room.close()`</Link>.
