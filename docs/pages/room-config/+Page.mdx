**Environment**: server.

<TelefuncStreamBeta />

```ts
// Environment: server

import { config } from 'telefunc'

config.room = {
  emptyTimeout: 300_000,    // A room nobody joined closes this long after nothing holds it (ms)
  departureTimeout: 20_000, // A room a member had joined closes this long after nothing holds it (ms)
}
```

> These are the defaults of every <Link href="/room">`Room`</Link>. The options of the same names to `Room.create()` and `Room.getOrCreate()` override them for the room they create. A room keeps the timeouts it was created with.

> `Infinity` keeps a room open until `Room.close()`.

> For what holds a room open, see <Link href="/room#when-a-room-closes" />.
