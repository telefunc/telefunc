Set how long a <Link href="/room">room</Link> stays open once nobody uses it.

```ts
// /server/index.ts
// Environment: server

import { roomConfig } from '@telefunc/room'

roomConfig.emptyTimeout = 300_000    // Close a room that nobody joined yet, once no page has it open (ms)
roomConfig.departureTimeout = 20_000 // Close a room after the last participant leaves and no page has it open (ms)
```

> Set them at your server entry, before your server creates rooms.

> Pass either timeout to `Room.create()` or `Room.getOrCreate()` to set it for one room, such as `Room.create('match-42', { emptyTimeout: Infinity, departureTimeout: Infinity })`. A room keeps the timeouts it was created with.

> `Infinity` keeps a room open until `Room.close()`. Set both to keep a room open before and after its first participant joins.

> For when a room closes, see <Link href="/room#close-a-room" />.
