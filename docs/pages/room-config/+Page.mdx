**Environment**: server.

<TelefuncStreamBeta />

```ts
// Environment: server

import { roomConfig } from '@telefunc/room'

roomConfig.emptyTimeout = 300_000    // A room nobody joined closes this long after no page has it open (ms)
roomConfig.departureTimeout = 20_000 // A room someone joined closes this long after nobody is in it and no page has it open (ms)
roomConfig.onDeliveryLost = (lost) => monitor.report(lost) // { roomId, reason } of a message, join or leave Room couldn't hand on; by default logged
```

> These are the defaults of every <Link href="/room">`Room`</Link>. The options of the same names to `Room.create()` and `Room.getOrCreate()` override them for the room they create. A room keeps the timeouts it was created with.

> `Infinity` keeps a room open until `Room.close()`.

> For when a room closes, see <Link href="/room#close-a-room" />.

> You usually set them at your server entry.
