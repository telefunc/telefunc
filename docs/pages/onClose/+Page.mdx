## Server lifecycle APIs

| API | Side | Type | Semantics |
|---|---|---|---|
| `getContext().onClose(cb)` | server | callback hook | Runs `cb` when the telefunction call closes, regardless of reason. |
| `getContext().signal` | server | `AbortSignal` | Aborts when the telefunction call closes. |
| <Link text={<code>channel.onClose(cb)</code>} href="/channel#lifecycle" /> | client & server | callback hook | Runs when that channel closes. |
| <Link text={<code>channel.onOpen(cb)</code>} href="/channel#lifecycle" /> | client & server | callback hook | Runs when that channel opens. |


## Client closing APIs

| API | Side | Close mode | Scope |
|---|---|---|---|
| `close(value)` | client | Graceful | Recursively closes streams/channels/files nested in `value`. |
| `gen.return()` / `break` | client | Graceful | One `AsyncGenerator`. |
| `reader.cancel()` | client | Graceful | One `ReadableStream`. |
| <Link text={<code>channel.close()</code>} href="/channel#lifecycle" /> | client & server | Graceful | One `Channel` / `BroadcastChannel`. |
| <Link text={<code>channel.abort(value?)</code>} href="/channel#lifecycle" /> | client & server | Immediate | One `Channel` / `BroadcastChannel`, with optional abort value. |
| `abort(call)` | client | Immediate | The in-flight call and any channels it opened. |
| <Link text={<code>{'withContext(fn, { signal })'}</code>} href="/withContext" /> | client | Immediate | Same scope as `abort(call)`, driven by an `AbortSignal`. |


## `onClose()` {#onclose}

**Environment**: server.

`onClose()` is available on the <Link href="/getContext">context object</Link>:

```ts
// Environment: server

import { getContext } from 'telefunc'

const { onClose } = getContext()
onClose(() => {
  // Release resources and stop upstream work
})
```

Use it to register teardown for resources created by the call (`setInterval`, event subscriptions, DB cursors, child processes, upstream streams).


## `signal` {#signal}

**Environment**: server.

`signal` is available on the <Link href="/getContext">context object</Link> and aborts at the same moment `onClose()` fires.

```ts
// Environment: server

import { getContext } from 'telefunc'

const { signal } = getContext()
await fetch('https://api.example.com/data', { signal })
```

Use it with APIs that accept an [`AbortSignal`](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal) to cancel in-flight work on call close.


## `close()`

**Environment**: client.

`close()` is exported by `telefunc/client`:

```ts
// Environment: client

import { close } from 'telefunc/client'
import { onLoadDashboard } from './Dashboard.telefunc'

const result = await onLoadDashboard()
close(result)
```

It gracefully closes all Telefunc values found recursively in `result`.


## `abort()`

**Environment**: client.

`abort()` is exported by `telefunc/client`:

```ts
// Environment: client

import { abort } from 'telefunc/client'
import { onLoadDashboard } from './Dashboard.telefunc'

const call = onLoadDashboard()
abort(call)
```

It immediately cancels the in-flight call (and channels opened by that call).
