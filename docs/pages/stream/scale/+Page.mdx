## Sticky sessions

Route every `/_telefunc` request from a given client to the same server so channels can reconnect. A stream that completes in one HTTP response, such as a returned `AsyncGenerator`, works on any server.

### Nginx — `ip_hash`

```nginx
# Inside the http block, e.g. /etc/nginx/conf.d/my-app.conf

upstream telefunc {
  ip_hash;
  server app1:3000;
  server app2:3000;
}

map $http_upgrade $connection_upgrade {
  default upgrade;
  '' close;
}

server {
  listen 80;

  location / {
    proxy_pass http://telefunc;
  }

  location /_telefunc {
    proxy_pass http://telefunc;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade; # WebSocket
    proxy_set_header Connection $connection_upgrade;
    proxy_set_header X-Forwarded-Host $http_host; # WebSocket origin check
    proxy_buffering off; # SSE
    proxy_read_timeout 1h;
  }
}
```

### HAProxy — cookie

```
frontend web
  mode http
  bind :80
  default_backend telefunc

backend telefunc
  mode http
  timeout tunnel 1h
  cookie SERVERID insert indirect nocache
  server app1 app1:3000 check cookie app1
  server app2 app2:3000 check cookie app2
```

### Caddy — `lb_policy cookie`

```
# Caddyfile

example.com {
  reverse_proxy app1:3000 app2:3000 {
    lb_policy cookie
  }
}
```

### Check it

Add a response header with the server's name. In the browser's network tab, check that `/_telefunc` requests reach the same server, including after going offline briefly and reconnecting.

### AWS ALB — target-group stickiness

In the target group's attributes, enable **Stickiness** with type **Load balancer generated cookie**.

## Broadcast

Use the default backend on one server. Across servers, install <Link href="/redis">`@telefunc/redis`</Link> or connect your broker to Broadcast with <Link href="/broadcast-config#custom-transports">`config.broadcast.transport`</Link>. Rooms work across servers with Redis or the Cloudflare adapter.

## Cloudflare

The <Link href="/stream/cloudflare">Cloudflare adapter</Link> handles session routing and delivers broadcasts and room messages across regions. Increase capacity with <Link href="/stream/cloudflare#scaling">`scale`</Link>.
