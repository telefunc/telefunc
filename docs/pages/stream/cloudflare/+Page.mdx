## Setup

Install Telefunc, Vite, Cloudflare's Vite plugin and Wrangler:

```bash
npm install telefunc
npm install --save-dev vite @cloudflare/vite-plugin wrangler
```

Add the Telefunc handler to your Worker:

```ts
// worker.ts
// Environment: server

import { Telefunc } from 'telefunc/cloudflare'

const telefunc = new Telefunc()

export const TelefuncDurableObject = telefunc.TelefuncDurableObject

export default {
  async fetch(request: Request, env: Env) {
    const response = await telefunc.serve({ request, env })
    if (response) return response

    // Your app's other routes
    return new Response('Not found', { status: 404 })
  },
}
```

Bind its Durable Object in Wrangler:

{/* spellcheck-ignore:on */}

```jsonc
// wrangler.jsonc
{
  "name": "my-app",
  "main": "./worker.ts",
  "compatibility_date": "2025-08-15", // or later
  "compatibility_flags": ["nodejs_als", "enable_request_signal"],
  "durable_objects": {
    "bindings": [
      { "name": "TelefuncDurableObject", "class_name": "TelefuncDurableObject" }
    ]
  },
  "migrations": [
    { "tag": "v1", "new_sqlite_classes": ["TelefuncDurableObject"] }
  ]
}
```

> Keep `nodejs_als` (or `nodejs_compat`) enabled to join rooms or subscribe to rooms or broadcasts from the server.

{/* spellcheck-ignore:off */}

> Run `npx wrangler types` to generate `Env`. Keep `enable_request_signal` to detect disconnects in <Link href="/onClose#context-signal">`context.signal` and `onClose()`</Link>.

Build the Worker with <Link href="/vite-plugin">Telefunc's Vite plugin</Link> and Cloudflare's [Vite plugin](https://developers.cloudflare.com/workers/vite-plugin/):

```ts
// vite.config.ts

import { defineConfig } from 'vite'
import { cloudflare } from '@cloudflare/vite-plugin'
import { telefunc } from 'telefunc/vite'

export default defineConfig({
  plugins: [telefunc(), cloudflare()],
})
```

Add your page as `index.html`, next to `vite.config.ts`:

```html
<!-- index.html -->

<!doctype html>
<html>
  <body>
    <script type="module" src="./main.ts"></script>
  </body>
</html>
```

Add the <Link href="/channel#new-channel">clock example</Link> with the browser code in `main.ts` and the telefunction in `Clock.telefunc.ts`. Run `npx vite dev` to develop, and `npx vite build` followed by `npx wrangler deploy` to deploy.

> For rooms, also install <Link href="/room#install">`@telefunc/room`</Link>. For apps that use regular telefunctions and streams, see <Link href="/serve" />.

## Context

Pass per-request data to telefunctions via <Link href="/getContext"><code>getContext()</code></Link>:

```ts
const telefunc = new Telefunc({
  context: async (request, env: Env) => ({
    user: await getUserFromCookie(request, env)
  })
})
```

See: <Link href="/Telefunc" />.


## Session affinity

Telefunc routes each client's channels to its [Durable Object](https://developers.cloudflare.com/durable-objects/) automatically.

<Warning>

If you proxy Telefunc requests, preserve the `session` and `home` query parameters and the `x-telefunc-home` response header. For a cross-origin client, expose `x-telefunc-home` with `Access-Control-Expose-Headers`.

</Warning>

## Rooms and broadcasts

Telefunc delivers room messages and broadcasts across regions. Call `Room.publish()` and `Broadcast.publish()` anywhere in your Worker, including cron triggers and queue consumers. Install server-side room and broadcast listeners in a telefunction or channel handler.

> A server-side subscription ends if Cloudflare evicts the session Durable Object that holds it.

## Scaling

By default, Telefunc creates one Durable Object per region. Increase capacity with `scale`:

```ts
const telefunc = new Telefunc({ scale: 4 })
```

This creates 4 Durable Objects per region, and Telefunc distributes sessions across them.

### Per-region scale

```ts
const telefunc = new Telefunc({
  scale: { weur: 5, enam: 3, apac: 2 },
})
```

Requests from regions you omit use <Link href="#configuration">`locationFallback`</Link>. Include that region in the map.


## Delivery guarantees

Channels hold reliable messages for reconnecting clients within <Link href="/channel-config">`config.channel.maxMemory`</Link> (64 MiB by default on Cloudflare). See <Link href="/channel#reconnection" />.

For broadcasts, await `subscription.opened` before relying on delivery. A publish resolves once it reaches every Durable Object registered for the key. If it rejects, some subscribers may already have received it, so publishing again can deliver it twice.

## Configuration

```js
const telefunc = new Telefunc({
  bindingName: 'TelefuncDurableObject',  // The binding's `name` in Wrangler (default)
  instanceName: 'telefunc',              // Base name for DO instances (default)
  scale: 1,                              // DOs per region (default)
  locationFallback: 'weur',              // Fallback region (default)
  jurisdiction: 'eu',                    // Restrict DOs to a jurisdiction (optional, no default)
})
```

See also: <Link href="/Telefunc" />.

## Workers Free

Workers Free allows 10 ms of [CPU time](https://developers.cloudflare.com/workers/platform/limits/#cpu-time) per HTTP request. A Worker that exceeds that CPU limit is stopped, and the client gets Error 1102.
