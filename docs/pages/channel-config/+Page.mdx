**Environment**: server.

<TelefuncStreamBeta />

```ts
// Environment: server

import { config } from 'telefunc'

config.channel = {
  reconnectTimeout: 60_000,  // How long a client may be gone and get its channels back (ms)
  pingInterval: 5_000,       // How often a client pings; it counts as gone after twice this (ms)
  maxMemory: '4g',           // The most this server's channels hold for clients, all together (bytes, or a size)
}
```

> **You rarely need any of these.** Await each `send()` before the next and no backlog builds up, whatever the client does.

> - `reconnectTimeout`: a client that comes back within it finds its channels open, with nothing lost. Past it, they close with `NetworkError`. Raise it for clients on bad networks. Lower it to free a gone client's channels sooner.
> - `pingInterval`: how fast a client that stopped answering counts as gone, which starts its `reconnectTimeout`. Raise it to save a phone's battery. Lower it to notice sooner.
> - `maxMemory`: a number of bytes, or a size such as `'4g'` or `'512m'`. It defaults to a quarter of the memory the process may use, so `'4g'` above is the default of a 16 GB machine. As it nears, the clients furthest behind a <Link href="/channel#new-broadcastchannel">`BroadcastChannel`</Link> miss their oldest messages first. Past it, a `send()` rejects with `ChannelOverflowError` and that message isn't delivered, and the channel stays open. One channel holds at most 320 MiB whatever its value, and a single message larger than it is refused even if you await it. Lower it to use less memory. Below 128 MiB, it also limits how fast messages arrive, in both directions: a channel sends at most half of it per round trip, so a distant client gets large transfers more slowly, the more so the closer it is to the 2 MiB minimum.

> On Cloudflare, `maxMemory` defaults to 64 MiB, as <Link href="/stream/cloudflare">a Durable Object's memory</Link> is limited to 128 MB.

> Telefunc refuses a value that can't work when you assign it: `reconnectTimeout` or `pingInterval` under 1 second, or `maxMemory` under 2 MiB. Assign `config.channel` before your server handles its first request: once a channel exists, a change is refused, as open channels would keep the old values.

> This is the **server-side** `config.channel`, a separate object from the **client-side** <Link href="/transport"><code>config.channel.transports</code></Link> (`telefunc/client`).
