**Environment**: server.

`provideTelefuncContext()` makes the `context` object available to telefunctions (via <Link href="/getContext">`getContext()`</Link>) — **it's useful when a telefunction runs outside <Link href="/Telefunc">Telefunc's server middleware</Link> and you therefore cannot pass the context to `serve({ context })`**, such as Server-Side Rendering (SSR) or tests.

```ts
// Environment: server

import { provideTelefuncContext } from 'telefunc'

const context = { userId: 42 }
// provideTelefuncContext() returns the value returned by onLoadTodoItems()
const { todoItems } = await provideTelefuncContext(context, () => {
  // Inside the onLoadTodoItems() telefunction, getContext() returns `context`.
  return onLoadTodoItems()
})
```

> With <Link href="/Telefunc">`new Telefunc()`</Link> or <Link href="/serve">`serve()`</Link>, the context is automatically provided to telefunctions — see <Link href="/getContext#provide" />. Reach for `provideTelefuncContext()` only when a telefunction runs outside both.
